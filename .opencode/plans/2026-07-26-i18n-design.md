# i18n: English + Indonesian (Toggle-only, no subpath)

**Date:** 2026-07-26
**Status:** Approved design

## Overview

Add internationalization support to the portfolio with two locales: `en` (English, default) and `id` (Indonesian). Uses `next-intl` in prefix-less mode — URLs remain clean without locale prefixes. Locale is stored in a cookie and toggled via a UI switch.

---

## Architecture

### Library: `next-intl`

| Feature | Choice |
|---------|--------|
| Routing | Prefix-less (no `/en` `/id` in URL) |
| Locale storage | Cookie `NEXT_LOCALE` |
| Fallback | `en` (default) |
| Server detection | `next-intl` middleware reads cookie |
| Client detection | `useLocale()` hook |

## Data Flow

```
User clicks EN/ID toggle
  → LanguageToggle sets cookie NEXT_LOCALE = 'en' | 'id'
  → window.location.reload()
  → Middleware reads cookie, sets request locale
  → layout wraps NextIntlClientProvider with messages
  → Server: getTranslations('namespace')
  → Client: useTranslations('namespace')
  → Data: getLocalizedData(locale)
```

---

## Translation Strategy

### Type A: UI Strings (labels, buttons, placeholders, aria-labels)
→ `messages/{locale}.json` via `useTranslations()`

### Type B: Content Data (projects, experience, skills, tech arsenal, explorations)
→ Locale-specific files `{data}/{locale}.ts`
→ Selected via helper `getLocalizedData(locale)`
→ NOT JSON because data contains TypeScript types (IconType, etc.)

---

## Data Helper API

```ts
// src/i18n/data.ts
export function getLocalizedProjects(locale: 'en' | 'id'): Project[]
export function getLocalizedExperience(locale: 'en' | 'id'): Experience[]
export function getLocalizedSkills(locale: 'en' | 'id'): SkillCategory[]
export function getLocalizedTechArsenal(locale: 'en' | 'id'): TechItem[]
export function getLocalizedExplorations(locale: 'en' | 'id'): Exploration[]
```

---

## Middleware

- Reads `NEXT_LOCALE` cookie
- Falls back to `en`
- Sets `x-next-locale` header
- Matches all routes except `api/`, `_next/`, static files

---

## LanguageToggle Component

- Placed in `Navbar.tsx` next to ThemeToggle (desktop + mobile drawer)
- Shows `EN` when ID active, `ID` when EN active
- Click → cookie → reload
- Style: pill button matching other nav items

## Edge Cases

| Case | Behavior |
|------|----------|
| No cookie | Fallback to `en` |
| Invalid cookie | Fallback to `en` |
| Missing translation key | next-intl shows key in dev, throws in prod |
| JS disabled | Default `en` (toggle won't work) |
| SEO | Single canonical URL, no impact |
